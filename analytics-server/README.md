# إحصائيات موقع OMAR

جاهزة للتشغيل، وتحتاج نشر الخدمة على استضافة تدعم Docker مع قرص دائم. GitHub Pages يستضيف ملفات الموقع فقط ولا يشغل هذه الخدمة.

1. انشر هذا المجلد كخدمة Docker عبر HTTPS.
2. اضبط `ADMIN_PASSWORD` على كلمة مرور خاصة طويلة (16 محرفًا على الأقل). لا تضعها في ملفات الموقع أو GitHub.
3. اضبط `ALLOWED_ORIGINS` على `https://omarnajjar52to-del.github.io`، أو عناوين موقعك مفصولة بفواصل، بلا شرطة نهائية.
4. اربط قرصًا دائمًا بالمسار `/data`. تحفظ قاعدة SQLite فيه. خذ نسخة احتياطية منه.
5. ضع عنوان الخدمة HTTPS في `assets/analytics-config.js` داخل ملفات الموقع، ثم ارفع الملفات إلى GitHub Pages.
6. افتح عنوان الخدمة `/admin` وسجّل دخولك. تعرض اللوحة الزيارات والجلسات وضغطات السوشل ميديا ومعارض الأعمال والأسماء الاختيارية.

لا يظهر نموذج الاسم ولا تُجمع بيانات قبل وضع عنوان الخدمة. ليس هناك بيانات تجريبية أو عداد عام مزيف. الاسم يرسَل فقط بعد موافقة الزائر. لا نطلب حساباته أو كلمة مروره. لا تخزن الخدمة عنوان IP في قاعدة البيانات، وتحتفظ بالأحداث 90 يومًا (يحذف القديم عند وصول أحداث جديدة). قد تحتفظ استضافتك بسجلاتها الخاصة.

الاسم مدخل ذاتيًا وليس تحققًا من الهوية. «زيارة» تعني تحميل الصفحة، و«جلسة» تعني جلسة تبويب في المتصفح؛ ليست عدد أشخاص مؤكدًا. الضغط على رابط لا يؤكد وصول الشخص إلى الوجهة. قد تمنع أدوات حجب التتبع بعض الطلبات. حماية كلمة المرور مطبقة على الخادم؛ ملفات اللوحة لا تتضمن كلمة المرور.

اختبار محلي فقط:

```bash
ADMIN_PASSWORD='choose-a-long-private-password' LOCAL_DEV=1 ALLOWED_ORIGINS='http://127.0.0.1:8765' python server.py
```

ضع `http://127.0.0.1:8080` مؤقتًا كعنوان الخدمة للاختبار المحلي، ثم أعد ضبطه إلى HTTPS عند النشر. لا تُضمّن ملفات قاعدة البيانات ضمن مستودع عام.
